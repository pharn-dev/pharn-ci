## Deviations from the plan's Approach (advisory)

- **`messages` in the v2 schema is not a `$ref` to v1.** `schema/report.v2.json` defines `$defs.message` itself,
  with the same fields and constraints as v1's. `packages/core/test/markdown.test.ts` (not in scope, unchanged)
  reads the "Known codes" list from the validator's schema, which is now v2. v2 documents its own code list there,
  so codes added in v2 are listed in v2. `tool`, `diffCoverage` and `agentSetup` still `$ref` v1.
- **`runMeta()` takes the commits from the same sources `getDiff` uses**, not from `getDiff`'s return value:
  - the pr-number target;
  - the payload pull request;
  - `merge_group`;
  - otherwise `context.sha` and a SHA-shaped `base-ref` or `payload.before`.

  A `base-ref` that is a branch or tag name is not recorded as `baseSha`.
- **One in-scope test edit was made through Bash** (`sed -i` on `packages/cli/test/ac-coverage-format.test.ts`,
  `toBe("1")` → `toBe(2)`), not the Edit tool. Every other file was written with the write tools. Golden fixtures
  were regenerated by `vitest -u` over the snapshot-owning test files. The only paths it wrote are in `## Files`.
